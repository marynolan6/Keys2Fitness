# AI task records

Copy the template below for each substantive AI-assisted task or demonstration. Keep the template reusable; save completed copies as separate task documents alongside the evidence described in `ai-evidence/README.md`. Use repository-relative links in records so another reviewer can follow them. Do not store credentials or private user data.

Record what actually happened, including rejected suggestions, failed checks, and skipped checks. AI self-review is not human review. Populate human-review fields only after the named reviewer performs that review; missing evidence stays pending. Never turn a suggested command into a claimed result.

## Reusable task-record template

### Identity and scope

- Task/story and acceptance criteria: pending
- Date/time/timezone, author, and starting revision/branch: pending
- Workspace absolute path: to be recorded
- Cline/VS Code versions and provider/model ID (Plan/Act): to be recorded
- Active project/global instruction sources and approval settings: to be recorded
- Permitted changes and explicit exclusions: pending

### Prompt and context

- Exact initial prompt (redact secrets and mark redactions): pending
- Relevant follow-up prompts/clarifications: pending
- Files, issue descriptions, or screenshots supplied as context: pending
- Approved plan and who approved it, if applicable: pending

### AI contribution

- What the AI inspected, proposed, generated, edited, or executed: pending
- Files changed and diff link: pending
- Suggestions accepted, modified, or rejected and why: pending
- Assumptions, data source (mock/local/Firebase), and limitations: pending

### Verification results

Record the command, absolute working directory, actual exit status, meaningful output summary, and evidence link for each check. For UI checks, record device/platform, dimensions/font scale, steps, and observed behavior. Do not claim all platforms were tested from one emulator run.

### Human review (must be completed by a human)

- Reviewer and review date: pending
- Diff/behavior inspected against acceptance criteria: pending

- Decision (approve / request changes / reject) and rationale: pending

### Traceability and evidence

- Genuine screenshot/task-export/log links and capture metadata: pending
